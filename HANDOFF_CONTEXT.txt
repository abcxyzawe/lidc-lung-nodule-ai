# LIDC Lung Nodule Detection — Handoff Context

File này tóm tắt mọi thứ ChatGPT/AI khác cần biết để hỗ trợ tiếp project.

## Mục tiêu

Hệ thống AI hỗ trợ bác sĩ tầm soát nodule phổi trên CT scan. Input DICOM folder → output:
- 3D segmentation nodules
- Phân loại malignancy
- Đánh giá Brock score + Lung-RADS
- Doctor confirm/reject từng nodule (persist verdict cho active learning sau này)

## Stack

- **Segmentation**: UNet++ EfficientNet-B5 SCSE 2.5D (in_channels=3)
- **FPR (False Positive Reduction)**: DenseNet121-3D, patches 48³
- **Lung mask**: lungmask R231 (Hofmanninger 2020)
- **Frontend**: Next.js 16 + React 19 + Tailwind v4 + shadcn
- **Backend**: FastAPI + uvicorn
- **Training**: PyTorch 2.5.1+cu121, MONAI (Tversky/DiceFocal losses), segmentation_models_pytorch

## Kết quả hiện tại (test_panel locked, 99 patients / 250 nodules)

| Pipeline | Sens | Prec | F1 | FP/scan |
|---|---|---|---|---|
| Baseline + FPR v2 (cũ) | 0.891 | 0.352 | 0.505 | 3.18 |
| **Stage2 + FPR v3 (WINNER)** | 0.787 | 0.509 | **0.618** | 1.46 |
| Δ | -0.10 | +0.16 | **+22% rel** | **-54%** |

**Winner config**: cons2 mask (≥2/4 radiologists) + Tversky α=0.3 β=0.7 + v1 data + 180ep + SWA. FPR threshold 0.85 on val.

## Cách team chạy app local

```bash
git clone https://github.com/abcxyzawe/lidc-lung-nodule-ai.git
cd lidc-lung-nodule-ai
git lfs pull          # Tải ckpts (~292MB)

# Copy ckpts về work/runs/ (webapp load từ đó)
cp work/runs_exp/stage2_full/best.pt work/runs/best.pt
cp work/runs_exp/stage2_full/best.pt work/runs/last.pt   # webapp load last.pt
cp work/runs_exp/stage2_full/swa.pt  work/runs/swa.pt
cp work/runs/fpr_v3_stage2winner.pt  work/runs/fpr.pt

# Install + run backend
pip install fastapi uvicorn paramiko segmentation-models-pytorch monai \
    h5py scipy scikit-learn lungmask plotly pylidc pydicom
cd src/webapp && PYTHONIOENCODING=utf-8 python app.py
# → http://127.0.0.1:8081

# Frontend (separate terminal)
cd frontend && npm install && npm run dev
# → http://127.0.0.1:3000
```

## API endpoints (FastAPI port 8081)

- `GET /api/health` → `{status: "ok"}`
- `GET /api/cases` → list các case đã analyze
- `POST /api/analyze` → upload DICOM ZIP/folder, trả case_id, stream events
- `GET /api/events/{case_id}` → SSE progress stream
- `GET /api/case/{case_id}` → trả meta + plot_html + verdicts
- `POST /api/case/{case_id}/verdict` → body `{nodule_id, verdict, reason?}` lưu doctor verdict
- `DELETE /api/case/{case_id}` → xoá case

## Workflow lịch sử (tóm tắt cho hiểu)

1. **Phase đầu (30h GPU)**: pilot 6 experiments (exp00-exp05) → train stage2_full v1 data → retrain FPR v3 → F1=0.606.
2. **Big Swing v2-NaN fix (14h GPU, failed)**: thử train stage2 với v2 data (full-CT slices) + smooth_dr=1.0 patch trong loss. Smoke pass nhưng full train val_dice không vượt baseline. Killed sớm theo recovery rule.
3. **3-phase optimization (5h GPU)**:
   - Re-tune detection params: F1 seg-only +0.019 (PROMOTED).
   - TTA4 + 3-ckpt ensemble: F1 -0.019 (NEGATIVE).
   - 5-slice retrain: val_dice 0.8757 cao hơn nhưng test F1=0.518 thấp hơn (NEGATIVE — val_dice không correlate F1).
4. **Hard-negative mining (in-progress khi VPS chết)**: chưa kịp hoàn thành.
5. **VPS bị xoá ngày 2026-05-14** — mất 50h GPU work + tất cả ckpts vì chưa pull về local. Lesson: phải auto-pull ngay sau mỗi milestone.
6. **Recovery run (6h GPU, 2026-05-15)**: re-train winner config trên VPS mới → F1=0.618 (cao hơn 0.606 lần đầu nhờ val_dice variance). Đã pull về local + push Git LFS.

## Bugs đã fix (đáng nhớ)

- `predict.py::render_3d_html`: sau khi `app.py` renumber `nodules[].id` theo confidence, mất sync với `labeled_pred` array → 3D mesh empty. Fix: lưu `original_id` + dùng nó.
- `app.py::_emit`: print tiếng Việt → cp1252 cannot encode → 500 error. Fix: `PYTHONIOENCODING=utf-8`.
- `findings-table.tsx`: verdict chỉ lưu localStorage → đóng tab mất. Fix: POST API + persist `verdicts.json` per case.
- `dataset_v2.py::make_loss`: MONAI TverskyLoss default `smooth_dr=1e-5` → AMP fp16 + pure-neg slices → NaN. Fix: `smooth_nr=1.0, smooth_dr=1.0, batch=True`.
- `tta_ensemble_eval.py`: z-score normalize blew up trên empty slices → NaN cache. Fix: HU clipping normalize giống `eval_experiment.py`.
